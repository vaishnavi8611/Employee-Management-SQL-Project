# Employee Management Database – SQL Server Project

## Project Overview
This project focuses on designing and analysing an Employee Management Database using Microsoft SQL Server.

It demonstrates practical SQL skills through database creation, data manipulation, business queries, joins, subqueries, CTEs, window functions and reusable SQL objects.

## Technologies Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
- GitHub

## Database Structure

The database contains three main tables:

1. **Employees** – Employee details, salary, hire date, department and manager information.
2. **Departments** – Department names and locations.
3. **JobRoles** – Job titles and salary ranges.

## SQL Concepts Covered

- Database and table creation
- Primary keys and foreign keys
- Constraints
- SELECT, WHERE, ORDER BY and DISTINCT
- Aggregate functions and GROUP BY
- INNER JOIN, LEFT JOIN and SELF JOIN
- Subqueries and correlated subqueries
- EXISTS and NOT EXISTS
- Common Table Expressions (CTEs)
- UNION and UNION ALL
- Window functions: ROW_NUMBER, RANK and DENSE_RANK
- LAG and LEAD
- Views
- Stored Procedures
- User-Defined Functions
- Date-based analysis
- Indexing fundamentals

## Business Problems

Completed 50 SQL business problems covering:

- Employee and department analysis
- Salary analysis
- Manager and employee relationships
- Department-wise reporting
- Ranking employees
- Hiring trends
- Monthly and quarterly hiring reports

## Project File

`EmployeeManagmentDB.sql` contains the database scripts and SQL practice queries.

This project helped develop practical SQL Server skills, database design knowledge, data analysis techniques and the ability to solve business problems using SQL.
